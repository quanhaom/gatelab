# LabGate — Export Intelligence

MVP điều phối kiểm nghiệm và vận chuyển lô sầu riêng xuất khẩu.

## Stack

- Next.js 15
- React 19
- TypeScript
- Recharts
- Leaflet / React Leaflet
- LocalStorage cho MVP local
- Chuẩn bị sẵn để nối Supabase + Vercel

## Chạy local

```bash
npm install
npm run dev
```

## Logo / branding

- Logo: `public/branding/logo.svg`
- Cấu hình tên sản phẩm: `lib/branding.ts`

## Các màn hình

- Dashboard + bản đồ lab tương tác
- Lô hàng + tạo lô + chuỗi lạnh 28 ngày
- Xếp hạng phòng kiểm nghiệm + đặt lịch
- Đề xuất vận chuyển + chọn phương án
- Báo cáo + chart hover
